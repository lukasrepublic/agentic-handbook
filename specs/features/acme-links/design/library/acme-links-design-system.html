AAcme Links

Design system v1.0 for the Acme Links link shortener. Indigo primary, Slate neutrals, Inter type, 4px spacing, 8px corners. Works in light and dark, and meets AA contrast.

v1.0 · Light + darkMeets AA contrastFirst consumer: dashboard

Implementation notes: the token core is plain CSS custom properties; in the app they are wired through Tailwind and owned components built on Radix primitives.
