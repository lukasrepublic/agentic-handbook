# `.foundry/` — factory runtime state (generated)

This directory holds Foundry's per-workspace runtime state. **It deliberately ships almost
empty**: everything here is generated by the factory as you use it, and most of it is
gitignored.

What lands here over time:

- **Review + audit evidence** (e.g. `security-audit.jsonl`, review ledgers) — append-only
  runtime records, gitignored; the durable ledger of *approvals* is git history itself (an
  authorized contract is a tracked file merged to `main`).
- **Certification + release state** — per-release evidence the verbs read back.
- **`build-provenance.yaml`** — *not here*: that file is emitted in the **code repo** at PR
  time, pinning the workspace commit its atom was authorized against. In a single-repo
  setup where workspace and code coincide, it appears at the repo root's `.foundry/`.

The rule of thumb: **nothing in `.foundry/` is hand-edited, and nothing load-bearing for
authorization lives only here.** If you delete this directory you lose local runtime
evidence, not authority — contracts, specs, and git history carry the authority.
